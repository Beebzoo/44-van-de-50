# Herkomst van de borden

De meeste borden komen uit de MIT-gelicentieerde set van NDW (github.com/ndwnu/qgis-verkeersborden-style). De onderstaande bestanden komen van Wikimedia Commons, met de licentie zoals Commons die vermeldt. Verkeersborden zijn in Nederland vrij van auteursrecht (Auteurswet artikel 11); de licentie geldt voor de tekening.
